# 藏笺 · 家用物品记录与采购清单软件

一款轻量、离线可用、支持电脑与手机无缝迁移的家用物品管理应用（PWA）。

## 核心功能

1. **家用物品库存管理**
   - 记录物品名称、**当前个数**（支持卡片上直接 `−` / `+` 快捷调整）、**计数单位**（内置常见单位并支持随时自定义）、分类、存放区域与具体位置描述。
   - **位置照片**：支持手机直接调用后置摄像头拍照，或从电脑/相册上传；自动压缩画质，既清晰又节省空间，点击可全屏查看大图。
   - **低库存提醒**：为物品设置提醒阈值，库存不足时自动高亮提示，可一键筛选待补货物品。

2. **可自定义采购清单**
   - 支持自由创建、重命名、删除多个采购清单（如「日常补货」「超市生鲜」「网购清单」「山姆囤货」等）。
   - 支持从库存物品一键加入采购，或点击「导入低库存」自动把需补货的物品加入清单。
   - 支持自由添加自定义采购项、设置紧急程度、勾选已采购，并支持**一键复制文本发微信**。
   - **采购完成一键入库**：勾选买好的商品后，一键自动把采购数量加回库存（未建档的物品会自动新建到库存中）。

3. **所有数据完整迁移到手机（含全部位置照片）**
   - 使用浏览器大容量本地数据库 `IndexedDB` 存储，突破传统 5MB 限制。
   - **方式一（离线完整迁移包）**：在「迁移与设置」中点击「导出完整迁移包 (.json)」，通过微信/AirDrop 发送到手机后，在手机端点击「导入迁移包」，支持**智能合并**或**完全覆盖恢复**。
   - **方式二（同 Wi-Fi 局域网一键互传）**：在电脑双击 `启动局域网手机访问.bat`，手机和电脑连接同一 Wi-Fi 并访问控制台显示的网址，即可一键无线推送/拉取全部数据，并可将网页「添加到主屏幕」作为手机 App 离线使用。

## 快速开始

- **电脑直接使用**：直接双击打开 `index.html` 即可开始记录（无需安装任何环境）。
- **手机使用 & 无线同步**：双击运行 `启动局域网手机访问.bat`，在手机浏览器输入窗口中显示的 `http://192.168.x.x:8088` 地址即可访问。
